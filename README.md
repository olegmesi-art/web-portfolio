# SHTR Studio

Преміальне брендове портфоліо студії розробки сайтів для бізнесу.

Українська та англійська версії перемикаються кнопками `UA / EN`. Усі чотири демонстраційні сайти також перекладені двома мовами.

## Як оновити сайт на GitHub

1. Розпакуйте ZIP-архів.
2. Відкрийте репозиторій `web-portfolio` на GitHub.
3. Натисніть `Add file` → `Upload files`.
4. Завантажте **весь вміст розпакованої папки**, щоб `index.html` був у корені репозиторію.
5. Підтвердьте заміну файлів і натисніть `Commit changes`.

Новий дизайн використовує ті самі адреси сторінок, тому налаштування GitHub Pages і Google Search Console змінювати не потрібно.

## Підключення Google Search Console

1. Додати ресурс типу `URL-prefix`: `https://shtr-studio.github.io/web-portfolio/`.
2. Завантажити у корінь репозиторію HTML-файл підтвердження, який видасть Google.
3. Після підтвердження відкрити розділ `Sitemaps` і додати `sitemap.xml`.
4. У перевірці URL надіслати на індексацію головну сторінку та `/rozrobka-saitiv/`.
